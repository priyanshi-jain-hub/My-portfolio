A single-page, responsive portfolio resume built with plain HTML, CSS, and JavaScript. No frameworks, no build step.

## Features
 
- Animated radar-sweep hero that lights up key achievements as the sweep passes
- Sections for education, experience, projects, patents, skills, and achievements
- Responsive layout for desktop, tablet, and mobile
- Respects the reduced-motion setting (the radar stays still)
- Print-friendly styles, so printing the page gives a clean resume
- Downloadable PDF version of the resume
## Deploy on GitHub Pages
 
1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` and the resume PDF to the main branch.
3. Go to **Settings > Pages**, set the source to the **main** branch, and save.
4. Your site will be live in a minute or two.
## Customize
 
- **Content:** edit the text directly in `index.html`.
- **Colors and fonts:** change the variables at the top of the `<style>` block (`--ink`, `--signal`, `--display`, `--body`).
- **Radar markers:** edit the `blips` array in the `<script>` block at the bottom of the file. Each marker has an angle (degrees clockwise from top), a radius (0 to 1), and a label.
## Tech
 
HTML5, CSS3 (custom properties, grid, flexbox), vanilla JavaScript (Canvas API), and Google Fonts (Bricolage Grotesque, IBM Plex Sans).
